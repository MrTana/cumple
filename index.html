    Configuración
    1. En console.cloud.google.com crea un proyecto y activa People API.
    2. Pantalla de consentimiento OAuth: tipo externo, agrega tu correo como usuario de prueba.
    3. Credenciales → ID de cliente OAuth → Aplicación web.
    4. En "Orígenes autorizados de JavaScript" agrega la dirección desde donde abres esta página (por ejemplo http://localhost:8080).
    5. Pega aquí el Client ID. Solo se pide permiso de lectura de contactos.
